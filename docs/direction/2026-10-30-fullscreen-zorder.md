# 전체 화면 숨김을 z순서로 판정 (2026-10-30)

- **문제**: 위젯은 포커스 창(`GetForegroundWindow`)이 위젯 모니터를 꽉 채울 때만 숨는다. 게임이 화면을 덮은 채로 다른 모니터를 클릭하거나 Alt+Tab을 누르면 포커스가 게임을 떠나고, topmost 위젯이 게임 위에 다시 나타난다.
- **풀 방향**: `foreground_covers`가 z순서를 위에서부터 훑어 **위젯 모니터에서 맨 위에 있는 창**이 전체 화면인지 본다. 내 프로세스·숨은 창·최소화·cloak된 창·셸 창·클릭 통과 오버레이(`WS_EX_TRANSPARENT`)·다른 모니터 창은 건너뛰고, 모니터를 채우지 않는 topmost 창(작은 항상 위 창, Alt+Tab 전환 화면)도 건너뛴다. 모니터를 채우지 않는 일반 창을 먼저 만나면 덮이지 않은 것으로 본다.
- **하지 않을 것**: 훅 스레드·Tk 타이머 구조 변경, 펼친 패널 고정 모드에 숨김 적용, 릴리스·버전 올림(사용자가 소스로 게임에서 확인한 뒤).
