# 현황판 정리 (2026-10-19)

- **문제**: 위젯이 작업표시줄 뒤로 깔려 사라진 것처럼 보인다. 전달에 확실히 실패한 Antigravity 요청이 `delivery_unknown`으로 남아 계속 진행 중으로 보이고, 해제도 미리보기도 안 된다. 메뉴는 항목이 많고 서로 겹친다.
- **방향**: 위젯이 작업표시줄 위에 계속 있도록 고친다. 확실한 전달 실패는 처음부터 실패로 기록하고, 이미 남은 요청은 진행 중 항목에서 "요청 닫기"로 정리한다.
- **메뉴**: 전역 메뉴에는 옵션…, 최신 버전 확인, 점검·복구 ▶(설치 상태 점검, 앱 호환성 점검, 스킬·훅 설치·복구), 숨기기, 종료만 남긴다. 보기 설정, 시작 시 실행, 업데이트 자동 확인은 옵션 창으로 옮기고 새로고침은 뺀다. 프로젝트 메뉴의 역할 지정과 모델·추론 설정은 하나로 합친다. 비활성 항목 위에서 하위 메뉴가 안 닫히는 버그도 고친다.
- **하지 않을 것**: 사용량 표시와 드래그·자석 모드의 손맛 개선은 이번에 넣지 않는다(별도 작업). 요청 닫기 외에는 새 기능을 넣지 않는다.
