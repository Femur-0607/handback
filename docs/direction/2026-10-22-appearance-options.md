# 현황판 모양 옵션 — 투명도·테마·드래그 핸들 (2026-10-22)

- **문제**: 현황판은 다크 고정이고(라이트 색은 도킹 중 밝은 작업 표시줄용뿐), 투명도는 펼쳐 보기 93%·작은 위젯 100%로 고정이다. 위젯은 어디를 눌러도 끌 수 있지만 누르면 패널·대화가 열려서 잡아 옮기기가 불안하다.
- **풀 방향**: 옵션 창 "모양" 절에 세 설정을 두고 `dashboard.json`에 저장한다.
  - `opacity`: 불투명도 100·90·80·70·60% 라디오, 기본 80(저장된 값이 있으면 그 값). 떠 있는 작은 위젯·펼친 패널·펼쳐 보기 창에 적용. 작업 표시줄에 도킹한 작은 위젯은 작업 표시줄 색 샘플에 이미 투명 효과가 들어 있으므로 100% 유지.
  - `theme`: 다크·라이트·시스템, 기본 다크(업그레이드해도 모양이 그대로). 시스템은 `AppsUseLightTheme`를 새로 고침마다 읽어 따라간다. 위젯·패널·메뉴·툴팁·옵션/결과 창 전부에 적용하고, 도킹 중인 위젯은 지금처럼 작업 표시줄 색을 따른다. 라이트 색은 기존 `compact_palette` 라이트 값과 `AGENT_COLORS_LIGHT`를 다시 쓴다.
  - `drag_handle`: 작은 위젯 위쪽의 얇은 가로 막대, 기본 켜짐. 도킹 중에도 보이며, 작업 표시줄 안에서는 막대를 조금 낮추고 두 줄이 들어가도록 글자를 줄인다. 막대에서는 이동 커서가 뜨고, 눌렀다 놓아도 패널이 열리지 않는다. 나머지 영역 드래그는 그대로 둔다.
- **하지 않을 것**: 펼쳐 보기 창의 핸들, 사용자 색 지정·강조색 선택, 투명도 슬라이더, 드래그·자석 동작(`dock_motion.py`) 변경, 릴리스·버전 올림.

## 후속 (2026-10-22, 소스 현황판으로 써 본 뒤)

- **문제**: 도킹하면 손잡이가 사라져 작업 표시줄에서 위젯을 잡을 곳이 없다. 기본 불투명도 100%는 사용자가 실제로 고른 80%와 다르다.
- **풀 방향**: 도킹 중에도 손잡이를 둔다(6 논리 px, 그만큼 글자 크기 계산에서 뺀다). 기본 불투명도를 80%로 바꾸고, 저장된 값은 그대로 쓴다.
- **하지 않을 것**: 도킹 위젯의 불투명도 적용(지금처럼 100%), 커밋은 사용자가 띄운 현황판에서 확인한 뒤에.
