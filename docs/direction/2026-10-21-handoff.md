# handoff 명령 — 방향과 계획 (2026-10-21)

상태: 구현 중(2026-10-21 시작). `docs/limitations.md` 1장의 "Future improvement: A `handoff` command"를 구현한다.

## 방향

- **문제**: Lead 대화가 길어져 새 Lead 세션을 열면, 토폴로지·열린 요청·ACK 안 된 결과·다음 할 일을 사람이 `status`, `inbox list`, `explain`을 차례로 돌려 모은 뒤 노트로 직접 써야 한다.
- **풀 방향**: `handback handoff --root <프로젝트>`가 읽기만 해서 Markdown 노트 한 장을 만든다. 새 Lead(사람이든 AI 세션이든)는 그 파일 하나만 읽고 바로 이어서 일할 수 있어야 한다.
- **하지 않을 것**: 열린 요청이나 ACK 안 된 결과를 새 Lead로 옮기기(재할당은 별도 후보), ACK·토폴로지 변경 같은 쓰기, AI 호출이나 대화 내용 요약, 대시보드 메뉴 연결(필요하면 나중에), 노트 자동 저장 주기.

## 노트 내용

1. 머리말: 프로젝트 루트, state home, 생성 시각(UTC와 로컬), handback 버전.
2. 토폴로지: 지금 Lead와 워커, 출처(저장값·환경 변수·기본값). `config.resolve(root, validate=False)`를 쓴다.
3. 열린 요청: `OPEN_STATES`에 있는 요청마다 id 앞 8자리, 대상 handle과 이름, 상태, 경과 시간, `return_to`. `state.requests()`와 `state.threads()`를 쓴다.
4. ACK 안 된 결과: 수신자별로 묶어 미리보기(앞 600자, 훅과 같은 길이)와 전체 envelope 경로, 결과 파일 경로. `inbox.pending(path, recipient)`를 쓴다.
5. 새 Lead가 실행할 명령: `use --lead "<새 주소>"`, 옛 주소 결과 확인용 `inbox list --for "<옛 주소>"`, `inbox watch --for "<옛 주소>"`, ACK 명령. 값은 실제 주소로 채워서 그대로 붙여 넣을 수 있게 한다.
6. 사람이 채울 칸: "결정 사항", "다음 할 일", "주의할 점". 빈 제목만 둔다.

## CLI

- `handback handoff --root <path> [--from <agent:id>] [--out <file> [--force]] [--json]`
- 기본은 stdout에 Markdown을 쓴다. `--out`이면 원자적으로 파일에 쓰고 경로만 출력한다. 이미 있는 파일은 `--force` 없이 덮어쓰지 않는다.
- `--from`은 넘겨주는 쪽 Lead 주소다. 기본은 지금 토폴로지의 Lead다. 붙여 넣을 명령의 "옛 주소"가 이 값이 된다.
- `--json`은 같은 내용을 구조화해서 내보낸다(테스트와 스킬용).
- 잠금은 잡지 않는다. 상태 파일은 원자적 교체로만 쓰이므로 파일 단위로는 일관되고, `status`·`inbox list`도 잠금 없이 읽는다. 상태 파일 하나가 깨져 있어도 그 항목에 "읽기 실패: <경로>"를 적고 나머지는 계속 쓴다(대시보드 `project_row`와 같은 방식).

## 구성

- `handback/handoff.py`(새 모듈): `collect(state, resolved, now=None) -> dict`와 `render_markdown(data) -> str`, 둘 다 순수 함수 위주로 둔다.
- `handback/cli.py`: 하위 명령 등록과 출력.
- 스킬 문서(`handback/skills/`): "Lead를 바꾸기 전에 `handoff --out`을 실행하고, 새 세션에 그 파일 경로를 넘긴다" 한 단락을 넣는다.
- `docs/limitations.md` 1장: Future improvement를 Current feature로 옮긴다. README의 명령 표에도 추가한다.

## 정한 것 (2026-10-21)

- 노트 위치: 기본 stdout, 저장은 사용자가 `--out`으로 정한다. state home에 자동 저장하지 않는다.
- 옛 Lead 주소: 기본은 지금 토폴로지의 Lead이고, `--from`으로 바꾼다.
- ACK 안 된 결과는 `result`/`error` 종류만 보인다. 열린 요청의 outgoing `request` 메일은 열린 요청 목록이 이미 보여 준다.
